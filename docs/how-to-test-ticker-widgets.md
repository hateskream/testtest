# How to Test Ticker Widgets

Данный файл описывает **как добавить и протестировать ticker-виджет** на тестовой странице.

Страница используется исключительно как тестовая и скрыта под фича-флагом `TICKER_WIDGET_PAGE_ENABLED`.

---

## Что это за страница

Тестовая страница позволяет:

- добавлять новые ticker-виджеты с помощью конфига
- быстро переключаться между виджетами
- проверять рендер одного виджета на множестве `tickerId`
- тестировать поведение виджета при разной ширине контейнера

Один виджет рендерится несколько раз - по одному на каждый тикер.

---

## Где добавляются виджеты

Все тестируемые виджеты описываются в массиве `widgets` (`src/pages/ticker-widget-page.vue:10`):

```ts
const widgets: ITickerWidgetConfig[] = [
  {
    name: 'activity-metrics',
    title: 'Activity Metrics',
    widget: ActivityMetricsTickerWidget,
    tickers: [
			'Crypto-BTC_Bitcoin',
			'Stock-TSLA',
			'Index-SPX',
			'Commodity-Gold',
			'Forex-USD',
			'Etf-SPY',
    ],
  },
] as const;
```

Каждый объект массива - один виджет для тестирования.

---

## Интерфейс конфигурации

```ts
interface ITickerWidgetConfig {
  name: string;
  title: string;
  widget: Component;
  tickers: TickerId[];
}
```

### Поля

- **name** - уникальный id виджета (используется в URL)
- **title** - название в UI
- **widget** - Vue-компонент виджета
- **tickers** - список тикеров, на которых виджет будет отрендерен

---

## Как добавить новый виджет (пошагово)

### Шаг 1. Импортировать компонент

```ts
import { MyTickerWidget } from '@/modules/widgets/my-widget';
```

---

### Шаг 2. Добавить конфигурацию в `widgets`

```ts
[
	...other,
	{
		name: 'my-widget',
		title: 'My Widget',
		widget: MyTickerWidget,
		tickers: [
			'Crypto-BTC_Bitcoin',
			'Stock-TSLA',
			'Index-SPX',
			'Commodity-Gold',
			'Forex-USD',
			'Etf-SPY'
		]
	}
]
```

#### Важно

- `name` должен быть уникальным
- `tickers` должны соответствовать типу `TickerId`
- используйте набор тикеров, достаточный для проверки. Если ваш виджет применим *ТОЛЬКО* для Crypto рынка, то укажите Crypto TickerId - и все.

---

### Шаг 3. Открыть виджет

Страница доступна напрямую по URL `/ticker-widget`

---

## Контракт виджета

Каждый ticker-виджет обязан принимать prop `meta` со следующим минимумом:

```ts
props: {
  meta: {
    tickerId: TickerId;
  };
}
```

---

## Тестирование ширины

На странице доступен контрол ширины контейнера:

- `range` — быстрое изменение
- `number` — точное значение
- `Reset` — возврат к значению по умолчанию (`320px`)

Ширина применяется ко всему контейнеру с виджетами и используется для проверки:

- адаптивности
- переполнений

---

## Поведение при ошибках

- если `widgetName` не найден — отображается **Not Found**
- если конфигурация отсутствует — виджеты не рендерятся
